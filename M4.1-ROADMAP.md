# M4.1 Live Cell/Range Formatting

Goal: provide live co-edit formatting operations through ONLYOFFICE spreadsheeteditor/callCommand, with structured live verification in the same open editor session.

Scope:
- font properties (where live API reliably exposes them)
- bold / italic
- text color
- fill/background color
- horizontal / vertical alignment
- wrap
- borders

Acceptance model:
1. write formatting through the live editor
2. read/inspect the same target from the same open editor session
3. compare expected vs actual
4. return PASS / FAIL / UNKNOWN fail-closed

Architecture constraints:
- no local Office engine
- no downloaded XLSX/ZIP/XML/OOXML fallback
- no WebDAV persisted-state as the primary live success proof
- browser/session must remain open until live verification completes

Development checklist:
- inventory existing formatting implementation before adding new code
- reuse proven live-editor helpers rather than duplicating them
- add/extend live formatting inspector only for fields that can be proven reliably
- positive and negative tests for each supported formatting family
- non-first worksheet and multi-cell range coverage
- mixed/unsupported getter cases must be UNKNOWN, not guessed
- architecture guard remains green
- full relevant regression/CI suite green
