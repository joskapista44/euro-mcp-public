# M4.3 — Row / Column Layout

## Scope

M4.3 adds live ONLYOFFICE spreadsheet row/column layout operations:

- set column width
- set row height
- hide/show rows and columns
- AutoFit rows and columns
- insert/delete rows and columns by reusing the existing M1.3 `workbook-ops.cjs` implementation

## Architecture boundary

All mutations target the CURRENT live ONLYOFFICE spreadsheet editor session. There is no local Office engine, downloaded XLSX/OOXML/ZIP/XML rewrite, DocBuilder fallback, or WebDAV persisted-state acceptance path.

## Verification contract

The acceptance rule is:

`write -> live read-back -> expected/actual -> PASS / FAIL / UNKNOWN`

- width: verify with `GetColumnWidth()`
- height: verify with `GetRowHeight()`
- hidden state: verify with `GetHidden()` on an entire row/column range
- AutoFit: measure resulting live dimension; unchanged or unmeasurable result is UNKNOWN rather than guessed PASS
- insert/delete: reuse M1.3 mutation path and report UNKNOWN until a generic content-independent structural postcondition can be proved

A measurable mismatch is FAIL. Lack of a trustworthy getter/postcondition is UNKNOWN. No unverified mutation may be promoted to PASS.

## MCP surface

`office_layout` in `euro-mcp-m43.cjs` is the M4.3 entry point. It extends the M4.2 server chain.

## Acceptance

M4.3 is code-complete when:

1. all scoped operations are exposed through the MCP tool;
2. measurable operations have same-session live verification;
3. structural operations reuse the existing workbook operation implementation;
4. tests guard PASS / FAIL / UNKNOWN behavior and the Document Server-only architecture;
5. the full repository CI/test suite passes.
